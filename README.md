# Minecraft Fabric Speed Mod

SpeedBoost is a Minecraft Fabric mod that changes player movement speed according to sprinting state: sprinting players receive a higher movement speed, while players who are not sprinting use the standard configured speed. It is a Fabric Minecraft mod with server tick event handling and Fabric API integration.

## Install

1. Install Java 25 or newer.
2. Install Fabric Loader 0.20.1 or newer for Minecraft 26.3.
3. Install Fabric API for Minecraft 26.3.
4. Place the SpeedBoost mod JAR in the server's `mods` folder.
5. Start or restart the Fabric server.

## Use

1. Join the Fabric server with a compatible Minecraft 26.3 client.
2. Sprint to receive the increased movement speed.
3. Stop sprinting to return to the regular configured movement speed.
4. The mod checks player sprinting status during each server tick.
